
## Parking Lot Design Using C++

#### About
 This Repo Contains the C++ code for the Design Of a Parking Lot Using OOP's. I built this Project as a part of my learning of OOP's and try to get a hands on exerience by mimicing some realworld scenerio.

 #### Assumptions
For my purpose, I have made the Following Assumptions:
- The parking lot has multiple levels. Each level has multiple rows of spots.
- The parking lot can park bike, cars, and buses.
- A bike requires single empty spot to park.
- A car requires 2 continuous empty spots.
- A bus requires 5 consecutive empty spots.
